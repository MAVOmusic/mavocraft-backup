## 3. FEATURES — paste into `✨┃features` (one block each)

```
🎮 THE GUIDE
The in-game book with everything (/updates).
- /updates (or /guide) - main menu
- /tutorial - step-by-step chapters (CH0 beginner -> CH15 Mob Farm)
- /whatsnew - latest update notes
It auto-opens once per server update.
```

```
⛏ PROFESSIONS (10)
Level professions by grinding with bound tools.
- /profession (or /prof) - start: click a profession, get its BOUND tool
- ONLY actions with bound tools give XP (creative never counts!)
- Tools: Stone -> Iron L10 -> Diamond L25 -> Netherite L50
- Enchants keep upgrading to L999
- /profession check, top <prof>, almost <prof>
- 10th = SLEEPER: /prof -> Sleeper -> bound bed -> place -> right-click at night (+1 XP)
```

```
🎖 PLAYER LEVEL
Your level = average of ALL professions + achievements.
- Everyone starts at Lv 1
- Seen in TAB: rank, name, level + % bar, coords, day, deaths
- /sb toggles the grind scoreboard
```

```
🏆 ACHIEVEMENTS (/ach)
52 categories - lifetime milestones that pay pocket money.
- /ach (or /achievements) - browse + claim rewards
- Every mob farm mob has its own kill category
- Everyone starts at level 1
```

```
📋 DAILY QUESTS (/quest)
10 fresh quests every day, paid in coins.
- /quest - board + claim
```

```
🔥 LOGIN STREAKS (/streak)
Log in daily, rewards grow with the streak.
- /streak - your streak
- /streak top - leaderboard
- Big bonus every 7th day, miss a day = reset
```

```
🪙 LUCKY COINS + WISHING WELL
~1 in 1,000 actions (mining/killing/fishing, 1 per 20s max).
- Toss them in the Wishing Well at spawn with Q
- Every prize is shop-sellable
- /ccollect - 1 free Lucky Coin every 10 MC days
- Also currency: casino, vault slots, grave teleports
```

```
💰 COINS & SHOP
Coins are the main currency. Sources:
- professions (per action), /quest, /ach, /streak
- /sell hand and /shop for raw materials
The shop is expensive on purpose - trade with villagers instead!
```

```
🧑🌾 VILLAGER ECONOMY
Villagers are the heart of progression.
- 1. Farm crops -> trade farmers for emeralds
- 2. Cure zombie villagers for discounts
- 3. Build a trading hall (librarians & smiths)
- 4. Buy gear with emeralds
- Master Traders at spawn take emeralds for premium stock (Mending, templates)
```

```
🐫 WANDERING TRADERS
A wandering trader visits a random online player every 30-60 min.
- Only useful offers, no junk (83 offers)
- Spawns with 2 llamas + bell, despawns after 10 min
- /wanderer - when the next visit happens
```

```
🏡 CHUNK CLAIMS
Protect your base.
- /chunk claim - claim the chunk you stand in
- First chunk FREE, prices rise in tiers, max 51 chunks
- /chunk access <player> - let a friend build
- /chunkprice - tiers + progress
- /borders - toggle border display
- 1-chunk buffer around claims stops edge griefing
```

```
🏠 HOMES & TELEPORTS
Homes are bound to beds in YOUR claimed chunks.
- Claim a chunk, place a bed, right-click it
- /home - teleport back | /homes - list & rename
- /spawn - back to the sky plaza
- Home Portal at spawn takes you to your first home
- Every teleport: 3s, moving cancels, monsters within 12 blocks block it
```

```
🌀 WILD TELEPORT
The only way out is through the WILD PORTAL at spawn.
- Stand inside 3s -> flung 5,000-400,000 blocks into fresh wilderness
- 5-min cooldown, no /wild command - spawn only
- Last 50 zones + 200m blacklisted so you don't land on someone
- Stock up at traders first - there is NO way back!
```

```
⚰ DEATH CHESTS
Die without losing everything.
- Items go into a locked grave chest only YOU can open
- /grave - menu with every grave: world, coords, time left
- Teleport cost scales with Player Level: 1,000 coins / 10 LC at Lv1,
  doubling each level (Lv5 = 16,000 / 160)
- 30 min lock, then it bursts open for anyone
```

```
📚 THE MUSEUM (/museum)
The Curator wants ONE of every item - 103 sections, 1,413 items.
- Click grey item in exhibit to donate (takes 1 from you)
- Deposit Crate: dump a haul, close it, new items register, dupes bounce back
- Complete a section: 1,000 coins per item in it
- Ranks at 25/50/75/100% completion = coin bonus + chat title
- /museum extras - buy ONLY what you still miss (normal shop prices)
```

```
🎰 LUCKY LOUIE'S CASINO (/casino)
Right-click the casino villager at spawn. 10 games:
Pick a Cup (2.7x), Coin Flip (2x), Dice Duel (2.3x), Crystal Wheel (0-10x),
TNT Tiles (up to 32x), Higher or Lower (4x), Rocket Crash (10x),
Lucky Slots (8x), Rock Paper Scissors (2x), Blackjack 21 (2.5x)
- Bets: 1-1,000,000 coins or 1-50 Lucky Coins
- 10 attempts per 10 MC days
- Hold a Gambler lucky stick: +1% win luck at L0 to +15% at L1000
```

## 4. 10 RECOMMENDED NEW FEATURES — paste into `🛠┃current-work`

```
1. PLAYER WARPS (/warp)
Players buy a warp slot and share their base.
- /warp create <name> (coins, e.g. 25k) - at your base
- /warp <name> - teleport (3s, same safety rules)
- /warps - public list, searchable
- Hard gates: 1 per player + expandable, cooldown per player
Why: wild spawns + 5-400k range means bases are far apart; warps = community.
```

```
2. CHEST SHOPS AT SPAWN MARKET
Player-run shops, not just the admin shop.
- /shop create price per stack + count; sign or chest GUI
- Economy shop sells real prices; chest shops = player economy
- Rent a market stall (coins/LC), 15x15 district
Why: villager-first economy + auction house exist; chest shops complete the loop.
```

```
3. WEEKLY BOSS RAID
One scheduled boss every weekend, server-wide.
- /boss - next raid time + join queue
- Spawns at a random arena zone, scaled HP per participants
- Loot: coins, LC, gear crates, trophy item
Why: events are timer-based mini bonuses; a big co-op set-piece is missing.
```

```
4. CUSTOM CRATES + KEYS
Reward chests from events/goals/quests.
- /crate <name> - vanity pools (common/rare/mythic)
- Keys from: daily quests, casino, community goal tiers, boss
- Crates can hold coins, LC, gear, vanities, pet skins
Why: gives quests/goals/events a physical payout + a coin sink.
```

```
5. DOUBLE XP WEEKENDS (SCHEDULED)
Schedule XP/coin multipliers server-side.
- /xpboost - next boosted time (config: Fri 18:00 - Sun 18:00)
- Applies to professions, achievements, quests
- TAB/bossbar shows remaining time
Why: keeps grind fresh, rewards weekend players, easy config.
```

```
6. AUCTION QUICK-BUY + BID TIMERS
Auction House QoL.
- Buy Now price + auto-extend on last-second bids
- Snipe protection + minimum raise %, delivery by mail
- Weekly featured auction (admin puts up a prize) - big community moment
Why: AH exists; timers make it a real marketplace + social event.
```

```
7. PET ABILITIES (PET 2.0)
Pets become optional helpers, not just cosmetics.
- Passive only, tiny: Pet carries 1 stack (1 slot), Pet picks up XP orbs
- Pet levels with you; no combat/damage
- Abilities toggleable; one active pet
Why: pets = coin sink already; abilities make them worth having.
```

```
8. FISHING TOURNAMENT
Weekly leaderboard event.
- /fishcomp - leaderboard + when it ends
- Counts fish caught (any rod), pays top 3 + participation coin
- Auto-runs weekends, randomized 2h window
Why: fishing exists only as profession/event bonus; a competitive mode is cheap to add.
```

```
9. MAIL SYSTEM
Items/coins between players without being online.
- /mail send <player> [coins] [item]
- /mail - read + claim; delivery box, 7-day expiry
Why: AH + trades need an item handoff; mail solves it and helps the community chest.
```

```
10. SEASONAL / THEMED EVENTS CALENDAR
Rotating content so the server never feels static.
- Halloween: pumpkin siege, candy drops
- Christmas: gift hunt, snowball arena
- Anniversary: double everything + cosmetics
- Config-driven: each season = event set + shop stock + lobbies
Why: real-server stickiness; reuses existing event/goal/crate systems.
```
